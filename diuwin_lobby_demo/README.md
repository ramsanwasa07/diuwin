# DiuWin Style Games Lobby - Original Demo

This ZIP is an original front-end demo inspired by the structure of a modern games lobby.

## Run
1. Extract ZIP.
2. Open folder in VS Code.
3. Open `index.html` directly in a browser, or use the VS Code Live Server extension.

## Included
- Responsive lobby layout
- Login/Register demo buttons
- Announcement ticker
- Game category tabs
- Recommended games cards
- RTP labels
- Demo winning feed
- Mobile bottom navigation
- Modal interactions

## Important
This package does not include copied proprietary source code, real-money gambling logic, payment processing, or account backend.
